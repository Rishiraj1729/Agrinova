# Agrinova

**Predict. Protect. Prosper. Recycle.**

**Made by Shikha Sharma • NCSE**

AI-powered agricultural intelligence + circular-economy platform — NCSC research prototype.

**Live:** [agrinova.vercel.app](https://agrinova.vercel.app)

## Run

```bash
npm install
npm run dev
```

## Key Routes

| Route | Description |
|-------|-------------|
| `/` | Home |
| `/analytics` | Deep impact analytics dashboard |
| `/farmer` | Farmer portal |
| `/business` | Business portal |
| `/research` | Research/Govt portal |
| `/science` | Science & Methodology |
| `/presentation` | Judge presentation mode |

## Deploy

```bash
npm run build
npx vercel --prod
```
