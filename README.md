# Agrinova

**Turning Crop Residue Into Farmer Income** — a demo marketplace to help farmers sell crop residue instead of burning it.

Inspired by solutions like KISANBANDHU, Agrinova connects farmers to biomass buyers, shared equipment, and tracks environmental impact.

## Demo Features

- **Landing page** — Problem, solution, quantified impact (before/after)
- **Farmer dashboard** — Earnings, listings, environmental impact stats
- **List residue** — Crop type, acres, quantity with auto buyer matching
- **Equipment booking** — Shared balers & Happy Seeders
- **Buyer marketplace** — Hardcoded buyers (biomass plants, paper mills, etc.)
- **Payment success** — Simulated payment flow

## Run Locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Tech Stack

- React + TypeScript + Vite
- Tailwind CSS v4

## Demo Flow

1. Click **Sell Residue** or **Start Selling Residue**
2. Fill in crop details and preview the buyer match
3. Book equipment for pickup
4. See payment confirmation and impact summary

All data is hardcoded for demo purposes — no backend required.
